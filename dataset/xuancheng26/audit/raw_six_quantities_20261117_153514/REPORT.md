# 宣城 2023 年 4 月六个原始物理量审计

本报告只描述原始单位上的数据分布。它不评价模型，也不把某一次训练的成败当成这些数字的解释。抽样种子 42–46 是同一批仿真日上的重复抽样，不是五个不同的真实交通日。

## 数据字典

| 量 | 字段 | 单位 | 时间支持 | 零值含义 | 来源 |
|---|---|---|---|---|---|
| I | inflow | 事件数 / 300 秒 | 区间 `[300k, 300(k+1))` | 该路该段没有进入事件 | 已发布独立事件计数 |
| O | outflow | 事件数 / 300 秒 | 同一区间 | 该路该段没有离开事件 | 已发布独立事件计数 |
| A_start | accumulation_start | 车辆 | 边界 `Q(300k-)` | 该边界快照上这条路没有车；`k=0` 时按定义是空网，不是午夜实测 | 已发布边界快照 |
| A_end | accumulation_end | 车辆 | 边界 `Q(300(k+1)-)`，末段是 `t=86399` | 结束边界上这条路没有车 | 已发布边界快照 |
| V | average_speed_raw | km/h | 区间内有效 1 秒快照的算术平均 | 存储上 `C=0,V=0` 表示没有有效速度观测；`C>0,V=0` 才是有效快照速度全为 0 | 本次按 all_sp_c 口径从 FCD 重算 |
| C | speed_observation_count | fcd_snapshot | 同一区间 | 没有计入均值的有效快照 | 同上 |

辅助量 U 是该路该 5 分钟内至少有一条有效速度快照的去重车辆数。`C/U` 是这些车平均贡献的快照条数。U 不是在场车辆总数，C 也不是去重车辆数，更不是 `C/300` 本身。一辆车停留 30 秒可以贡献 30 条。

原始 1 秒速度是 m/s，汇总时只乘一次 3.6。负速度、非有限速度、internal lane 和未知 lane 不进入 V/C；超过道路限速或超过 40 m/s 的有限非负速度仍然保留，不截断、不用限速填补。有效速度分布以 `C>0` 为主，另给包含填零的存储分布。

四状态是独立提取的。残差 `r = A_end - A_start - I + O` 只作描述。当前口径是 `Q(b-)`：首段起点 `Q(0-)=0`，段末取 `t=300(k+1)-1`。相邻段满足 `A_end[k]=A_start[k+1]`，这和区间守恒不是同一件事。每天一次独立仿真，差分不跨日。

## 范围和做法

日期来自 `shared/split_manifest.json`，共 29 天：2023_04_01 至 2023_04_30，缺 2023-04-09。星期按公历计算，没有套用法定节假日日历。节点 1406 个，每天 288 个 5 分钟段。基本单位是 `(date, road, 5min)`，每个单位计一次。全量只计一次。

全量单元格数 n=11,742,912。固定观测是 p05/p10/p20/p30/p40/p50/p70，种子 42–46。核心波动观测是 p5_p15 与 p10_p20，各有 30min/1h/2h/day，种子 42–46。p5_p35 的四种频率另列，不混进核心对照。部分观测的主表按种子分开；种子之间再给均值、标准差和最小最大。

I/O/A 来自已发布日文件，并与 `sequence_targets_12step/*/full_raw` 核对。V/C/U 来自每个仿真日一次 FCD 流式扫描，29 个日期工人同时跑。抽样名单没有重抽。扫描缓存在 `/tmp/xuancheng26_raw_audit_20261117/cache`，没有写入 `training_data`。

计数分位数来自全部单元格，方法是 NumPy 的 linear percentile。速度单元格均值用 float32 保存后再算分位数。快照层直方图是 1 km/h 分箱，格内快照分位数只对全量计算，分辨率 1 km/h。格内速度标准差由快照和与平方和精确得到，直方图步长 0.5 km/h。

## 3. 同一条路怎样变，路和路怎样不同

相邻 5 分钟、同一条路、同一天：I 的平均绝对变化是 2.92 辆事件，绝对变化中位数 1，两端都为 0 的比例 33.79%。O 的平均绝对变化是 3.07。A_end 的平均绝对变化是 1.14 辆。C 的平均绝对变化是 120 条快照。

15/30/60 分钟（lag=3/6/12）上，I 的平均绝对变化分别是 3.18、3.63、4.66。变化幅度随间隔拉长，但 5 分钟已经不是噪声级别的抖动。对称相对变化在双零时记为 NA，不加入伪小数；I 在可计算配对上的中位数是 0.333。

速度变化只在两端都有观测时计算。这样的配对有 6,884,019 个，平均绝对变化 4.35 km/h，中位数 2.44 km/h。相邻格从无观测到有观测的比例是 3.77%，从有观测到无观测是 3.82%。这两种切换不是速度变化。

道路内部、按单元格等权的方差分解 `Var=E[Var|road]+Var(E|road)`：I 的组内份额 51.85%，组间份额 48.15%，恒等式残差 5.68434e-14。A_end 的组间份额 35.85%，C 的组间份额 45.21%。有效速度的单元格权重不均衡，I 的分解是平衡面板，V 的分解按有效单元格加权；另给了道路等权的对照，见 `tables/roads/variance_decomposition.csv`。

## 4. 日内形状和日期

全路网进入事件的平均日内曲线在时间格 92（07:40 起的 5 分钟）达到均值 38,355.6 辆事件/5 分钟；前两小时的平均网络流入是 2,617.4。流出峰值时间格是 92，全网 A_end 峰值时间格是 92，C 的峰值时间格是 93。快照加权速度的峰值时间格是 65。流量、快照数和存量的高峰时段接近，但存量峰值不必和进入峰值落在同一格。图见 `figures/fig04_diurnal.png`。

快照加权均速 `sum(V*C)/sum(C)` 与有效单元格等权均速是两个数。全时段快照加权均速是 27.6 km/h，等权均速是 34.5 km/h。后者把每条有观测的路段时间格算一票，不是全体车辆的均速。

自相关按路、按日计算，常数序列记 NA。I 的 lag1 平均相关 0.705（有效序列 32,090），lag12 为 0.532。去掉每条路自己的平均日内形状后，I 的 lag1 降到 0.24。A_end 的 lag1 是 0.271，去形状后是 0.0876。有效速度的 lag1 是 0.148。流入在 5 分钟和 60 分钟上都比存量、速度更有持续性；存量的原始 lag1 只有 0.271，并不是比流量更黏。去掉日内形状后，三个量的 lag1 都明显下降，说明原始相关里有很大一块是重复的日内形状。

流入曲线相对同星期其他日期的偏离分（平均绝对差 / 典型曲线均值）最大的日期是 2023_04_05（周三，score=0.362，对照 3 天）、2023_04_29（周六，score=0.246，对照 4 天）、2023_04_23（周日，score=0.194，对照 3 天）、2023_04_04（周二，score=0.185，对照 3 天）、2023_04_06（周四，score=0.165，对照 3 天）。这只说明形状偏离同星期的平均，不事先指定异常日，也不解释成节假日。

## 5. 六个量怎样一起出现

全量单元格上，I 与 O 的 Pearson 相关是 0.987，Spearman 是 0.993（n=11,742,912）。I 与 A_end 的 Pearson 是 0.606 。在 `C>0` 上，V 与 I 的 Pearson 是 0.00547，V 与 A_end 是 -0.184，V 与 C 是 -0.219。去掉道路均值后，I 与 O 的池化相关降到 0.975，道路相关的中位数是 0.977。再去掉路×时刻平均形状后，I 与 O 的池化相关是 0.932。

含 V 的相关只使用 `C>0` 的单元格，并在表里写了 n。I 与 O 去掉道路均值后仍有 0.975，去掉路×时刻平均形状后仍有 0.932，所以这对流量的同步主要发生在同一条路内部，不是只因为忙路的各项都大。V 与 I 的相关接近 0，V 与存量、C 是弱的负相关。这些中心化只用于描述，不是训练预处理。数字在 `tables/joint/correlation_full.csv`。

四状态零/非零组合里占比不低于 1% 的有：四状态全 0 占 37.38%（4,389,936 格），这些格子的 C 全部为 0；I 与 O 都为正、两端存量都为 0 占 22.03%；四状态都为正占 21.42%；只有结束存量或只有起始存量为正、且 I 与 O 都为正，各约 9.0%。四状态全 0 但 C>0 的格子数是 0。I=0 且至少一个存量为正的格子存在，但很少：例如 O 为正、A_start 为正、A_end 为 0 有 69,173 格（0.59%），两端存量都为正且 I 与 O 都为 0 只有 9 格。区间事件和边界快照本来就不是同一种计数，这些少见组合不能直接判成数据错误。

给定 I 的分箱后，O、存量和有效速度的范围仍然宽。I 在 6-10（n=1,057,496）时，O 的 p10/p50/p90 是 5/8/11，A_end 是 0/0/3，有效 V 的 p10/p50/p90 是 12.7/35.3/55.2 km/h（n_V=1,057,496）。 I 在 21-50（n=1,948,342）时，O 的 p10/p50/p90 是 21/31/45，A_end 是 0/2/10，有效 V 的 p10/p50/p90 是 11.7/35.4/55.3 km/h（n_V=1,948,342）。 I 在 51-100（n=428,937）时，O 的 p10/p50/p90 是 49/61/85，A_end 是 0/7/22，有效 V 的 p10/p50/p90 是 11.9/37.2/54.4 km/h（n_V=428,937）。

残差 r 的单元格 n=11,742,912。其中 11,742,898 格为 0，正的 7 格、负的 7 格，非零比例 1.19e-6，取值只有 +1 或 -1。绝对差的中位数和 p95 都是 0。这 14 格没有被改写。占比显示成 100% 会把这 14 格抹掉，所以这里用原始计数。`A_end[k]` 与下一段 `A_start` 相同是边界定义，不是要求 r=0。

## 6. C 里是更多车，还是同一辆车停得更久

在 U>0 的单元格上，C/U 的中位数是 23.9 条快照/车，p90 是 59.2，均值是 29.4（n=7,349,230）。车辆在单个 road×bin 的贡献次数（贡献直方图）中位数对应分箱 22.0 条。有 18.16% 的有车单元格里，单车最大快照数超过该格 C 的 50%。快照加权均速是 27.6 km/h，先对车再对车等权的网络均值是 37.4 km/h。单元格上 |V-V_vehicle| 的均值是 2.95 km/h。两种加权都只是诊断，不表示哪一种更正确。C 与 U 的 Pearson 相关是 0.759。

全量快照里速度为 0 的比例是 29.65%。格内速度标准差（有观测的格子）中位数约 10 km/h，p90 约 24.5 km/h，分辨率 0.5 km/h。格内快照 p90-p10 的中位数约 24 km/h，分辨率 1 km/h。跨格的 V 变化和格内离散是两件事。

`C/300` 与 `(A_start+A_end)/2` 的单元格相关是 0.936（n=11,742,912）。二者之差的中位数是 0，这是大量接近 0 的格子把中位数压住了，不是两个序列逐格相等。前者接近有效快照口径下的区间平均在场量，后者只有两个端点，而且内部车道上的车不计进入存量。

有效单元格里 V 超过该路限速的比例是 2.60%，快照层超过限速的比例是 10.47%。这些值保留，不自动当成错误。

## 7. 抽样之后分布变成什么样

固定渗透率是对当天出发车辆的一个排列取前缀，数量为 `floor(n*p)`，不是独立伯努利抽样。波动渗透率是按车辆实际出发所在段，对这个固定排列的段内前缀取样；车辆一旦入选，整条轨迹保留，后面不再重抽。day 模式没有日内 p 切换。下面的比例是道路时段上的有效观测比例，不等于 schedule 上的名义 p。

固定 p10 上，全量流入为正的格子里观测流入为 0 的比例，五个种子平均是 0.378；`sum(I_obs)/sum(I_full)` 平均是 0.100。这两个数不是一回事。30 分钟 p5–p15 的名义均值是 10%，但没有固定 p15 时不能假装有严格同均值对照。它的 P(obs=0|full>0) 平均是 0.384，事件和之比平均是 0.101，固定 p10 分别是 0.378 和 0.100。day 模式的 p5–p15 没有日内换段，P(obs=0|full>0) 平均是 0.382，事件和之比平均是 0.103。p10–p20 的名义均值是 15%。30 分钟方案的事件和之比平均是 0.151。作为两侧参考，固定 p10 是 0.100，固定 p20 是 0.200，这不是 15% 的严格对照。V 不是子集计数，不要求 V_obs≤V_full。速度差只在双方 C>0 时计算，全量有速度而抽样缺失的比例单列在配对表。

30min p5_p15 的名义 p 均值 0.1016（最小 0.0500，最大 0.1499），按出发车辆加权的实际选中比例 0.1014；30min p10_p20 的名义 p 均值 0.1516（最小 0.1000，最大 0.1999），按出发车辆加权的实际选中比例 0.1514；1h p5_p15 的名义 p 均值 0.0986（最小 0.0500，最大 0.1496），按出发车辆加权的实际选中比例 0.0982；1h p10_p20 的名义 p 均值 0.1486（最小 0.1000，最大 0.1996），按出发车辆加权的实际选中比例 0.1482；2h p5_p15 的名义 p 均值 0.1037（最小 0.0505，最大 0.1496），按出发车辆加权的实际选中比例 0.1040；2h p10_p20 的名义 p 均值 0.1537（最小 0.1005，最大 0.1996），按出发车辆加权的实际选中比例 0.1540；day p5_p15 的名义 p 均值 0.1021（最小 0.0630，最大 0.1497），按出发车辆加权的实际选中比例 0.1027；day p10_p20 的名义 p 均值 0.1521（最小 0.1130，最大 0.1997），按出发车辆加权的实际选中比例 0.1527。实际选中比例来自 `floor(组大小×p)`，所以和名义 p 有离散取整差。day 模式一天只有一个 p。

## 8. 哪些结果稳，哪些只是口径

全量的尺度、零值占比和日内峰值时段是在 29 天上汇总的，不依赖抽样种子。固定 p10 的 I 中位数在五个种子上都是 0，因为抽样后零值占到约 61.4%；更能看出种子是否稳定的是均值和零值占比。I 均值的种子平均是 1.097，种子标准差 0.00093，范围 1.095–1.098。零值占比的种子平均是 61.44%，种子标准差 0.019 个百分点。事件和之比 `sum(I_obs)/sum(I_full)` 在种子之间也只在 0.100 附近小幅变动，见 `tables/sampling/seed_spread.csv`。流入最高 1% 单元格占事件和的 8.44%，这个长尾在全量上稳定存在；换一个种子改变的是哪些车被看见。日期形状分最高的那几天只在少数日期上出现，不能写成每一天都这样。

下面这些是口径造成的，不是交通突然消失：首段存量为 0、`C=0` 时 V 被存成 0、内部车道不计入道路存量、到达只在 tripinfo 有到达时刻时补流出、残差不必为 0、`A_end[k]=A_start[k+1]`。抽样后的零观测比例高于全量，是车辆名单变短，不是全量交通变了。

当前数据不能回答的事：法定节假日是否解释了某一天的形状偏差；超过限速的快照在仿真里对应什么驾驶行为；残差里的每一类事件各占多少（事件分类计数没有在本次扫描里重算，四状态用的是已发布文件）。相关强弱也不被写成某种网络结构必然有效或无效。
