## 与无约束 A 的数值对照

| 实验 | 测试 Inflow MAE |
|---|---:|
| A 原始预测 | 2.4540 ± 0.0043 |
| C 投影前 | 2.4399 ± 0.0080 |
| C 投影后 | 2.4383 ± 0.0079 |

A 减 C 投影后为 0.015725。其中 A 减 C 投影前为 0.014090，投影步骤再贡献 0.001635。这两项相加等于 A 与 C 投影后的差，投影步骤占这个差的 10.4%。这是同一批指标上的数值分解，不是两个独立训练模型之间的因果效应。

位置数量和 MAE 的方向不一致：五种子平均有 52.54% 的位置绝对误差变大，47.31% 变小。小于 0.5 辆车的位置占全部样本约四成，这一组的 MAE 上升；10 辆车以上的位置 MAE 下降更大，所以整体 MAE 仍然下降。
