# 空间与时间误差

预测文件是测试集 `test_predictions.npz` 里的 `pred_raw` 和 `y_raw`。验证集预测不进入这一节，因为检查点是按验证误差挑选的。没有重新训练。

- 测试预测共复核 407 组。`target_slot == window_start_slot + 11` 且时间片落在当天 0–287 的有 407 组。
- 测试日与 manifest 的 5 天、每天 277 个窗口、窗口起点为 0..276 的有 407 组。
- 由 `pred_raw` 与 `y_raw` 重算的 MAE 相对 `test_metrics.json` 的最大绝对差是 0.000e+00；分通道最大绝对差是 0.000e+00。
- 标签数组哈希冲突 0 组。同一家族、任务、通道和渗透率下，各模型面对的是同一份测试标签。
- 3 秒相位单通道 inflow 的 35 组测试预测与四状态 single-to-single inflow 逐字节相同（35/35）。下文不把这 35 组当作另一次独立实验。

道路编号使用 `r_nodes.csv` 的 `edge_id`，节点顺序与两套数据的 `node_order_sha256` 一致。每条道路的 MAE、RMSE、偏差和测试均值在 `tables/node_metrics.csv.gz`。

## 空间

项目里没有现成的低、中、高流量道路分组。这里用该通道在测试集上的道路平均真实值，把平均值大于 0 的道路分成三等分。零均值道路单独称为 inactive，不放进三分位。

高流量组的 MAE 明显高于低流量组。p05 的 inflow 上，高组 MAE 大约是低组的 5.8–7.8 倍。1406 条道路里有 266 条在该测试集上的平均 inflow 为 0，没有进入三分位；其余每组 380 条。低组的平均真实值上界约 6.0，高组超过约 19.8。绝对误差随流量尺度上升，不等于相对误差也更差。Inflow 上各模型的高/低比值接近；存量上 TLAST 的比值小于图模型，但高流量道路仍然更难。当前差距不是由“只有某一个模型能重建高流量道路”造成的。

p05 的 single-to-single inflow 上，六种模型误差最高的约 10% 道路：6 个模型各自 MAE 最高的约 10% 道路中，共同出现 104 条（每组大约 141 条）。

p05 的 accumulation start：6 个模型各自 MAE 最高的约 10% 道路中，共同出现 112 条（每组大约 141 条）。
道路 MAE 的两两相关范围是 0.98–1.00；最低的一对是 S2S-GCN-LSTM 与 TLAST（0.98）。

难重建的道路在模型之间高度重合。换模型没有把误差从一组道路搬到另一组道路。共同出现的边编号写在 `tables/hard_road_overlap.csv`。

## 系统性偏差

偏差定义为预测减真实值。正值是高估。

原始单通道，按整张测试张量：p05 平均偏差 -1.059 到 -0.160，高估样本比例 49.4%–65.8%，预测与真实值相关系数 0.959–0.964；p70 平均偏差 -0.246 到 -0.018，高估样本比例 33.2%–54.6%，预测与真实值相关系数 0.895–0.994。

四状态 single-to-single inflow：p05 平均偏差 -1.038 到 -0.202，高估样本比例 32.1%–63.6%，预测与真实值相关系数 0.932–0.967；p70 平均偏差 -0.233 到 -0.087，高估样本比例 34.9%–55.2%，预测与真实值相关系数 0.979–0.994。

整体平均偏差为负：p05 的 single-to-single inflow 上，STGCN 约 −0.20，Graph WaveNet 约 −0.39，TLAST 和 S2S 约 −0.88，STID 约 −1.04。平均偏差为负并不等于大多数样本都被低估。Graph WaveNet 在 p05 inflow 上有 63.6% 的样本预测偏高，但偏高的幅度小于偏低的幅度，所以均值仍是 −0.39。TLAST 只有 32.1% 的样本偏高。相关系数在 inflow 上大约 0.93–0.97，在 accumulation 上大约 0.81–0.93，存量预测和真实值的线性关系更弱。

STID 在四状态 inflow、p05 上按真实值分箱：0 MAE 0.122 / 偏差 0.121，(0,2] MAE 0.949 / 偏差 0.063，(2,5] MAE 1.704 / 偏差 -0.300，(5,10] MAE 2.712 / 偏差 -0.477，(10,20] MAE 3.873 / 偏差 -0.712，>20 MAE 7.330 / 偏差 -4.163。

TLAST 同一设置：0 MAE 0.257 / 偏差 0.015，(0,2] MAE 0.945 / 偏差 0.134，(2,5] MAE 1.695 / 偏差 -0.194，(5,10] MAE 2.639 / 偏差 -0.322，(10,20] MAE 3.723 / 偏差 -0.542，>20 MAE 6.833 / 偏差 -3.529。

S2S 同一设置：0 MAE 0.284 / 偏差 0.263，(0,2] MAE 1.578 / 偏差 0.285，(2,5] MAE 2.673 / 偏差 0.054，(5,10] MAE 3.998 / 偏差 0.154，(10,20] MAE 5.396 / 偏差 0.059，>20 MAE 9.355 / 偏差 -4.630。

真实值为 0 时，偏差非负：STID 约 +0.12，TLAST 约 +0.02，S2S 约 +0.26。真实值超过 20 时，三个模型的偏差都在 −3.5 到 −4.6。高流量被低估是共同的；零值和中等流量上的符号则因模型而异，S2S 在 10 以下的箱子里偏差为正。负预测没有在指标里被截成 0；`metrics_long.csv` 里的 `negative_prediction_fraction` 记录了比例。
