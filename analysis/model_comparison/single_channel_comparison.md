# 单通道 inflow 重建

这一节只比较原始信号配时上的单通道实验。3 秒相位单通道与四状态 inflow 的 single-to-single 预测相同，放在四状态报告里，不在这里重复排名。

参与全部 7 个渗透率的是 STID、STGCN、DCRNN、Graph WaveNet。S2S-GCN-LSTM 只有 p70。TLAST 没有这套结果。单位是每条道路、每个 5 分钟时间片的车辆数。MAPE 和 WAPE 已经是百分数。

相对差距小于 2% 时，本文只把它记为小差距。这不是显著性检验。

各渗透率 MAE 最低的模型：p05 为 Graph WaveNet（MAE 2.609，与 STGCN 相差 2.3%）；p10 为 STGCN（MAE 2.451，与 Graph WaveNet 相差 0.7%）；p20 为 STGCN（MAE 2.174，与 STID 相差 0.3%）；p30 为 STGCN（MAE 1.954，与 STID 相差 0.1%）；p40 为 STID（MAE 1.738，与 Graph WaveNet 相差 0.7%）；p50 为 STID（MAE 1.531，与 Graph WaveNet 相差 0.8%）；p70 为 STID（MAE 1.124，与 Graph WaveNet 相差 0.5%）。

去掉只有 p70 的 S2S 后，前两名的差距：p05 前两名差距 2.3%，超过 2% 的报告阈值；p10 前两名差距 0.7%；p20 前两名差距 0.3%；p30 前两名差距 0.1%；p40 前两名差距 0.7%；p50 前两名差距 0.8%；p70 前两名差距 0.5%。

没有一个模型在 7 个渗透率上都是 MAE 最低。p05 是 Graph WaveNet，p10–p30 是 STGCN，p40–p70 是 STID。除 p05 的第二名差距为 2.3%、p70 的 STGCN 落后 3.1% 以外，这四个模型之间的差距都低于 2%。p10–p50 上，四者的 MAE 可以看成同一水平。p70 的 S2S MAE 是 4.392，比 STID 高 290.7%。这个数字来自 100 epoch 的协议运行；同目录的搜索试验和 Gaussian 边权运行更低，但仍然明显差于另外四个模型，而且不属于这张表的协议。

## 可以保留的判断

在这套单通道 inflow 上，STID、STGCN、DCRNN 和 Graph WaveNet 没有拉开有实际意义的稳定差距。低渗透率下 Graph WaveNet 略低，高渗透率下 STID 略低，中间渗透率几乎重合。S2S-GCN-LSTM 在唯一完成的 p70 上明显更差，但该运行的训练预算和另一次搜索不一致，不能单独用来估计这个结构的全部潜力。TLAST 没有加入这套比较。
